# Git 仓库内容与构建准备

本仓库保存源码、场景配置、说明文档、测试和测试所需的固定夹具。ZIP、运行结果、原始采集证据、日志、验证输出、构建缓存、已编译程序和本机配置不提交；本地原文件仍保留。

## 代码入口

- 根目录的 `run.py`、`memscenes/`、`apps/`、`native/`、`tools/`：共享场景框架与负载应用源码，运行和构建步骤见根目录 `README.md`。
- `sen1/`、`sen2/`：原有场景脚本与配置。
- `常驻服务代码/memshift_cpp/memshift_cpp/`：C++ 常驻服务、控制工具、测试及构建脚本，见其中的 `README_zh.md`。
- `交付/内存场景复现包_20261006/`：包含场景 1–4 的独立入口、源码、配置及说明。
- `交付/场景1独立复现包_20261007/`：场景 1 独立版本的源码、配置及说明。

## 从 Git 克隆后的准备

原有交付包 README 中“随包提供”的 HAP、压力程序、HDC、USB 运行库和归档证据属于本地交付资产，本源码仓库不包含这些文件。首次运行前，请按对应 README 使用 DevEco Studio / HarmonyOS SDK 构建应用和原生程序，安装测试应用，并提供本机 HDC 路径。C++ 服务按其 CMake 和 `tools/build_harmony.ps1` 说明构建。

`sen1/scripts/` 保留辅助程序的 C 源码；已有脚本依赖的 `bin/` 可执行文件、`tools/hdc.exe` 等需要自行构建或从 SDK 提供。`sen1/data/` 中的本地输入表格也未提交。

原有说明文档中的 `results/`、`evidence/` 链接指向本地历史采集，Git 克隆中没有这些历史文件。测试目录中的固定夹具仍保留，供离线测试使用。新的运行结果与构建产物由 `.gitignore` 排除。
